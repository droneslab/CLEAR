# CLEAR

Official code repository for **CLEAR**, a semantic-geometric terrain abstraction framework for scalable off-road planning.

## Code release

The source code and reproducibility instructions are scheduled for release on **September 8, 2026**.

Until then, the project website, paper, videos, and results are available on the [CLEAR project page](https://droneslab.github.io/CLEAR/).

Please watch this repository for the release announcement.

## Project website

The project website is maintained independently in the [`gh-pages`](https://github.com/droneslab/CLEAR/tree/gh-pages) branch so that the `main` branch remains dedicated to the code release.
